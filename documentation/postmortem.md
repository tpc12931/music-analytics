# AI assistant as a partner — STUDENT REFLECTION REQUIRED

This document intentionally contains prompts, not invented first-person personal experience.

- Which assistant-generated suggestions did you accept, reject, or change? Why?
- How did you verify the raw data, correlations, sample design, model limitations, and the difference between historical association and forecasting?
- Did the assistant make a misleading assumption? How did you catch or correct it? (A useful example to consider: a charting dataset that cannot identify non-charting songs; another: a model with seemingly high accuracy that predicts no hits.)
- Which parts of the process did you personally control? What would you do differently without the assistant?
- What were AI's strongest and weakest contributions to your work?

Use only your authentic experience and interpretation when completing this postmortem.
